# Мышцы — тренажёр

Карточки с интервальными повторениями по таблице 15.2 «Основные мышцы тела человека и их функции»: 46 мышц с иллюстрациями, 32 обратных вопроса, режим «узнать мышцу по картинке».

## Что где лежит

| Файл | В репозиторий? | Что это |
|---|---|---|
| `index.html` | да | всё приложение |
| `firebase-config.js` | да | конфиг Firebase (не секретный) |
| `firestore.rules` | да (для справки) | правила доступа — вставляются в консоль Firebase |
| `content.json` | **нет** (в `.gitignore`) | собранные материалы для загрузки в Firestore |
| `content-src/` | **нет** (в `.gitignore`) | исходники материалов: тексты, подсказки, картинки и скрипт сборки |

Материалы хранятся в Firestore, и прочитать их можно только после входа через Google с email из списка доступа. Сайт и репозиторий публичные, но в них только код. Картинки по прямой ссылке не открыть.

## Настройка (≈15 минут, бесплатный тариф Spark)

1. https://console.firebase.google.com → **Add project**.
2. **Authentication → Get started → Sign-in method**:
   - **Google → Enable** (вход через Google);
   - **Email/Password → Enable** и ниже включите **Email link (passwordless sign-in)**. Это вход по ссылке на почту для тех, у кого нет Google-аккаунта: человек вводит email, получает письмо и нажимает ссылку. Пароль включать не обязательно.
3. **Authentication → Settings → Authorized domains → Add domain** → `<ваш-логин>.github.io`.
4. **Firestore Database → Create database** → любой регион → *production mode*.
5. **Firestore → Rules**: вставьте содержимое `firestore.rules`, впишите свой email (владелец) и email людей, которым даёте доступ → **Publish**.
   Чтобы потом добавить человека, допишите его email в список и снова нажмите Publish.
6. **Project settings → Your apps → Web (`</>`)** → скопируйте `firebaseConfig` в `firebase-config.js`.
7. Залейте `index.html`, `firebase-config.js`, `firestore.rules`, `.gitignore` в репозиторий → **Settings → Pages → Deploy from a branch → main / root**.
8. Откройте сайт, войдите **своим** (владельца) аккаунтом. Появится экран «Материалов пока нет» → выберите `content.json` с компьютера. Загрузка займёт несколько секунд.
   Позже материалы можно обновить через ⚙ → «Обновить материалы».

После этого остальные заходят на сайт, входят через Google, и у каждого свой прогресс, общий для его телефона и компьютера. Если email нет в списке, человек видит экран «Нет доступа».

**Вход по ссылке на почту** нужен один раз на каждом устройстве, дальше сессия сохраняется. Письма от Firebase иногда попадают в «Спам». В списке доступа в `firestore.rules` email пишется маленькими буквами.

## Как обновить материалы

Всё, что видно на сайте, лежит в `content-src/`:

- `muscles.json` — 46 мышц: `name`, `o` (начало), `i` (прикрепление), `f` (функции), `hint` (подсказка «Как запомнить»), `g` (блок: `trunk` / `arm` / `leg`);
- `reverse.json` — обратные вопросы (`q` — вопрос, `a` — ответ);
- `rules.html` — вкладка «Правила»;
- `groups.json` — названия блоков;
- `images/` — картинки: `1.jpg` … `46.jpg` по номеру мышцы, `front.jpg` / `back.jpg` — обзорные.

Порядок:

1. Поправьте нужный файл (или замените картинку файлом с тем же именем, до ~900 КБ).
2. В корне проекта выполните `node content-src/build-content.mjs`. Скрипт проверит данные и пересоберёт `content.json`.
3. Откройте сайт под владельцем → ⚙ → «Обновить материалы» → выберите `content.json`.

Остальные увидят изменения при следующем открытии сайта. Прогресс не пропадёт, он привязан к номеру мышцы. Поэтому номера `n` не меняйте: если поменять номер, карточки этой мышцы начнутся заново.

Мелкую опечатку можно исправить и прямо в консоли: Firestore → Data → `content` → `main` → поле `muscles`. Но тогда не забудьте внести ту же правку в `content-src`, иначе следующая загрузка её перезапишет.

## Проверка без Firebase

Если в `firebase-config.js` стоит `null`, сайт берёт `content.json` из той же папки, а прогресс хранит только в браузере. Удобно для локальной проверки: `python3 -m http.server` в папке → http://localhost:8000.

## Как пользоваться

- **Тренировка**: выберите блок и типы вопросов (начало, прикрепление, функции, узнать по картинке, обратные). Сначала идут карточки к повторению, потом новые. Ответьте сами, откройте ответ и оцените себя: «Не помню» вернёт карточку через пару карточек, «Трудно / Помню / Легко» отложат её на 1 день, 3 дня, неделю и дальше.
- **Прогнать всё**: все выбранные карточки вперемешку, расписание не меняется. Для повторения накануне экзамена.
- **Правила**: обзорные рисунки и закономерности с мнемониками.
- **Таблица**: полный текст с картинками и поиском, например «седалищный» или «отводит бедро».
- Картинки увеличиваются по нажатию.
